# STYLE-DNA - шаблон вкуса (подмешивать в каждую генерацию)

Заполни под свой бренд. В проде хвост промта живёт в `project/prompts/style_tail.txt`.

## Два допустимых грейда
- Светлый editorial: окно, воздух, чёткие тени, Kodak Portra.
- Тёмный editorial: чистый чёрный, один блик (хром, лак, мокрый камень). Без мутной «ночной» каши.

Не смешивать оба грейда в одной карусели.

## Кадр
- Faceless: деталь, POV сверху, кроп, руки, со спины. Лицо целиком и фигура в рост - нет.
- Один акцентный цвет на кадр.
- Предмет в живой обстановке, не по центру на постаменте.

## Нельзя
- бренды, лого, читаемый текст в фото;
- CGI / 3D / сток-мокап;
- чужой пин как есть (только редроу);
- полные лица и рост.

## Хвост промта
См. `project/prompts/style_tail.txt`. Меняешь вкус - меняй этот файл, не код.
